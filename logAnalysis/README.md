# 📈 YC 日志分析平台 使用说明

**适用脚本：** `logAnalysis/logAnalysis.py`
**界面框架：** PyQt5 + pyqtgraph
**配置文件：** `logAnalysis/configs/data_formats.json`

---

## 1. 工具概览

本工具用于解析并可视化机器人控制日志：既可以把**历史日志文件/文件夹**整批读进来离线分析，也可以通过 **SSH** 连接设备，对运行中的日志做**实时监控与绘图**。

### 核心特性

* **配置驱动解析**：日志字段、列数、在线路径全部由 `data_formats.json` 描述，支持 `slave`（从手）/ `boom`（吊臂）/ `master`（主手）/ `lout`（ADS）四种格式自动识别。
* **离线整批加载**：支持单文件、整个文件夹、以及**多文件拖拽**（按文件首行时间戳自动排序拼接）。
* **缓存加速**：文件夹首次加载后生成 `_combined_cache.pkl` 缓存，再次加载直接读缓存。
* **在线实时绘图**：按需记录——**把某个臂的数据列拖进绘图区，才开始记录该臂**；无数据的臂会自动停止读取。
* **交互式绘图**：拖拽建曲线、差分、双游标测量、鼠标悬浮取值、跟随最新数据、水平/垂直分栏、时间跳转。
* **崩溃可诊断**：内置运行日志、原生崩溃堆栈捕获与未处理异常过滤器（详见第 5 节）。

## 2. 运行与环境

### 2.1 依赖

```bash
pip install PyQt5 pyqtgraph pandas numpy paramiko
```

> 缓存已从 parquet 改为 pickle，**不再需要 pyarrow**。

### 2.2 直接运行

```bash
python logAnalysis/logAnalysis.py
```

### 2.3 打包为 exe

```bash
cd logAnalysis
pyinstaller logAnalysis.spec
```

打包配置 `logAnalysis.spec` 的几个要点（改动前请先读注释）：

| 项 | 说明 |
| :--- | :--- |
| `upx=False` | UPX 压缩 Qt / 原生 DLL 会导致换机后**静默崩溃**，务必保持关闭 |
| `datas` 含 `configs/data_formats.json` | 让 exe 单独拷到别的电脑也能解析日志 |
| `datas` 含 `logAnalysis.ico` | 运行时窗口/任务栏图标与 exe 图标**共用同一份** `.ico` |
| 未打包 pyarrow | 缓存改用 pickle 后已移除该原生依赖 |

## 3. 界面结构与操作

```
MainWindow
├─ 左栏（QScrollArea，窗口不够高时整体滚动）
│  ├─ 工作模式：离线模式 / 在线模式（切换时自动停止当前监控）
│  ├─ 离线：本地路径 + 选项（启用缓存 / 使用相对时间）
│  ├─ 在线：设备类型 / SSH连接 / 监控控制 / 数据缓冲区
│  ├─ 数据列树（按臂分组，把列拖到右侧绘图区即出曲线）
│  └─ 清除当前页所有曲线 / 保存当前页图像
└─ 右侧绘图区（QTabWidget）
   └─ PlotTab
      └─ QSplitter（水平或垂直分栏）
         └─ PlotSubWidget × N
            └─ DropPlotWidget（pyqtgraph）+ 曲线 + 游标 + 悬浮提示
```

### 3.1 离线模式

1. **选择文件 / 选择文件夹**，或直接把文件/文件夹**拖入窗口**。
2. 点击 **加载**。
   * 拖入**多个文件**时，本地路径框显示 `拖放 N 个文件`；再次点“加载”会复用这批文件。
   * 手动修改路径框内容后，之前的多文件选择即失效。
3. **选项**：
   * `启用缓存`：文件夹加载结果缓存为 `<文件夹>/_combined_cache.pkl`，下次秒开。旧版 `_combined_cache.parquet` 会被自动清理。
   * `使用相对时间`：忽略日志原始时间戳，按行号生成时间轴（默认开启）。
   * `重建缓存`：删除缓存后重新解析（仅在选中文件夹且启用缓存时可用）。
4. **取消**：中止当前加载任务。

> 数据列数超过 150 时会询问是否只保留前 150 列，避免绘图卡顿。

### 3.2 在线模式

1. 选择**设备类型**（从手 / 主手 / ADS，取自配置文件的 `online_paths`）。
2. 填写 **SSH 连接**信息（IP / 端口 / 用户名 / 密码）。
3. 点击 **连接并开始监控**。连接成功后各臂的日志会被持续读取。
4. 把左侧某个臂的数据列**拖入绘图区**，该臂才开始记录并绘图（其余臂保持空闲，不占带宽与内存）。
5. **暂停 / 继续**（快捷键 `P`）：暂停后可自由拖动、缩放、回看已缓存的数据。
6. **数据缓冲区 → 保留时间**（1–120 s）：决定绘图区可以回看的时间跨度，也决定内存占用上限。

> 某个臂超过 10 秒没有任何数据时，会自动停止该臂的读取（不影响其他臂）。

在线数据流：

```
SSH(paramiko)
   └─ LiveThread（每个臂一个线程）
        └─ new_batch 信号
             └─ MainWindow 环形缓冲 deque（只保留「保留时间」内的数据）
                  └─ QTimer 每 50ms 刷新
                       └─ PlotSubWidget.update_curves() → 曲线重绘
```

离线数据流：

```
文件/文件夹 → LoadThread → FormatConfig 逐行解析 → pandas.DataFrame
                                    │
                                    ├─ 写缓存 <文件夹>/_combined_cache.pkl
                                    └─ finished 信号 → 填充数据列树 + 绘图区
```

### 3.3 绘图区

* **建曲线**：从数据列树把列名拖到某个子视图。
* **分栏**：右上角工具条的“水平分栏（左右并排）”/“垂直分栏（上下堆叠）”。
* **新建标签页**：工具条 `+`；每个标签页标题上自带关闭按钮。
* **跟随 / 关闭子视图**：鼠标**移到该子视图上才显示**的右上角悬浮按钮（`»` 为跟随最新数据）。
* **差分**：在**图例上点右键** → 显示/隐藏差分（相邻采样点差值），曲线名带 `[diff]` 后缀，颜色沿用基曲线。
* **游标 A / B**：工具条 `A`（红）/ `B`（蓝）按钮开启，用于读取某一时刻各曲线的数值与时间。
* **时间跳转**：工具条时钟按钮或按 `J`，输入目标时间（会记住上次输入）。
* **保存图像**：左栏“保存当前页图像”，支持 PNG/JPEG/BMP。

### 3.4 鼠标操作

| 操作 | 效果 |
| :--- | :--- |
| **左键拖动** | 平移视图 |
| **中键拖动** | 框选放大（拉出矩形，松开后缩放到该区域） |
| **右键拖动** | 缩放（水平/垂直拖动分别改变横/纵向比例） |
| **滚轮** | 缩放 |
| **右键点图例** | 弹出菜单：显示/隐藏差分、删除曲线 |
| **双击绘图区** | 所有子图跳到最新数据并开启跟随 |
| **悬浮在曲线上** | 显示该点横纵坐标（多条曲线重合时**全部列出**，按各自颜色区分） |

### 3.5 快捷键

| 按键 | 效果 |
| :--- | :--- |
| `J` | 打开时间跳转对话框 |
| `P` | 暂停 / 继续（在线模式） |
| `Tab` | 在已开启的游标 A / B 之间切换“活动游标” |
| `←` / `→` | 活动游标左/右移动 1 ms |
| `S` | 以当前子视图的 X 轴范围同步其他所有子图 |
| `T` | 以第一个子视图的 X 轴范围同步其他所有子图 |

## 4. 配置驱动解析

解析规则完全由 `configs/data_formats.json` 描述（各字段含义、增删字段、列数验算见
[`configs/config_guide.md`](configs/config_guide.md)）。

配置文件的查找顺序（前者优先，便于现场覆盖）：

1. **程序同级目录** `configs/data_formats.json`
2. **exe 内置资源**：单文件 exe 会解包到 `%TEMP%\_MEIxxxxxx\configs\`，所以日志里可能看到临时目录路径——这是正常的
3. **源码内嵌默认配置** `DEFAULT_CONFIG_JSON`（在 `logAnalysis.py` 中）

> 修改 `configs/data_formats.json` 时，若希望内嵌默认值同步，需一并更新代码里的 `DEFAULT_CONFIG_JSON`。

## 5. 日志与崩溃诊断

打包为窗口程序（`console=False`）后 stdout/stderr 不可见，因此所有的诊断信息都写入文件：

* **日志位置**：`<exe 或脚本所在目录>/logs/logAnalysis.log`；该目录不可写时回退到 `%TEMP%\logAnalysis_logs`。
* **启动即记录实际生效的配置**：

  ```
  配置文件加载成功: ...\configs\data_formats.json
  配置来源: 程序同级配置文件：...\configs\data_formats.json
  日志格式: slave=142列(简表92列), boom=36列, master=119列, lout(ADS正则=\[ADS\])
  在线设备: 从手[arm1,arm2,arm3,arm4,boom]; 主手[left,right]; ADS[ADS]
  ```

* **原生崩溃**：`faulthandler` 写入 C 级堆栈；`SetUnhandledExceptionFilter` 捕获致命异常并反查崩溃模块（DLL/exe 名）与访问地址。
* **Python 异常**：全局 excepthook 记录堆栈，并做了**同类去重 + 弹窗总量上限**，避免高频异常引发弹窗风暴。

排查换机闪退时，重点看日志里的“配置来源”“可执行文件”与崩溃模块名。

## 6. 代码结构速查

| 类 / 函数 | 职责 |
| :--- | :--- |
| `FormatConfig` | 读取配置、生成列名、按行解析各格式日志 |
| `LoadThread` | 离线加载线程（文件夹 / 多文件 / 缓存重建） |
| `LiveThread` | 在线单臂监控线程（SSH 读取 + 按需记录 + 无数据自停） |
| `TimeAxis` | 底部时间轴刻度格式化（秒/毫秒自适应） |
| `LeftPanViewBox` | 鼠标交互：左键平移、中键框选放大、右键缩放 |
| `DropPlotWidget` | 支持拖拽建曲线的 pyqtgraph 控件 + 右上角悬浮按钮显隐 |
| `PlotSubWidget` | 单个子视图：曲线、游标、差分、悬浮取值、跟随 |
| `PlotTab` | 一个标签页：多个子视图的分栏管理与游标同步 |
| `MainWindow` | 主窗口：左右栏装配、模式切换、缓冲区与刷新定时器 |
| `describe_config` | 生成“实际生效配置”的日志摘要 |

## 7. 常见问题

| 现象 | 可能原因 | 处理 |
| :--- | :--- | :--- |
| 加载后提示“未找到有效日志数据” | 日志格式不在配置中 | 对照 `config_guide.md` 核对 `detect` / `fields` 配置 |
| 加载很慢 | 首次解析大文件夹 | 勾选“启用缓存”，或点“重建缓存”后重试 |
| 在线模式一直没有曲线 | 未把该臂的数据列拖入绘图区 | 从左侧数据列树拖拽对应列进绘图区 |
| 某个臂自动停止 | 该臂 10s 内无数据 | 检查设备日志是否有输出，重连即可 |
| exe 换到别的电脑闪退 | UPX 压缩 / 缺少内置资源 | 确认 `upx=False`，用 `logAnalysis.spec` 重新打包 |
| 窗口/任务栏图标异常 | 图标未随 exe 打包 | 确认 `datas` 含 `logAnalysis.ico` 后重新打包 |

# 🛠️ XML参数管理工具 V1.0 使用说明

**最后更新：** 2026年4月25日
**适用版本：** `xmltool.py` (支持GUI/CLI双模式)

## 1. 工具概览
本工具是一款专为工业配置文件（XML）设计的跨平台管理工具。它不仅能处理本地文件，还能通过 **SSH 协议** 直接管理远程服务器上的 XML 文件，并提供可视化的**本地与远程差异对比**功能。

### 核心特性
*   **双模式运行**：自动检测环境，有 GUI 则启动窗口，无 GUI 则降级为命令行。
*   **远程直连**：无需先下载文件，直接通过 SSH 读写远程服务器上的 XML。
*   **差异对比**：直观展示本地与远程服务器文件的参数差异，并支持双向同步。
*   **智能编码**：自动检测文件编码（UTF-8/GBK等），防止乱码。

---

## 2. 环境部署

### 2.1 依赖库安装
工具依赖 `paramiko` (SSH) 和 `chardet` (编码检测)。请确保已安装 Python 3.6+，并在终端执行：
```bash
pip install paramiko chardet
```

### 2.2 启动方式
直接运行脚本，工具会自动选择界面模式：
```bash
python xmltool.py
```
*   **Windows/Linux 桌面环境**：自动启动 GUI 图形界面。
*   **Linux 服务器/无界面环境**：自动启动 CLI 命令行交互界面。

---

## 3. 图形界面 (GUI) 详解

GUI 版本采用现代化风格设计，支持深色/浅色主题。

### 3.1 顶部模式栏
*   **运行模式**：切换 `本地模式` 与 `远程模式(SSH)`。
    *   *切换至远程模式时，会自动展开 SSH 连接栏。*
*   **操作范围**：切换 `批量(目录)` 与 `单个(XML)`。支持仅针对一个文件操作，或递归处理整个文件夹。

### 3.2 SSH 连接模块 (远程模式)
当选择“远程模式”时，需填写以下信息：
*   **主机/端口**：远程服务器 IP 和 SSH 端口（默认 22）。
*   **用户名/密码**：具有文件读写权限的账号。
*   **状态指示**：连接成功后，状态灯变为绿色。

### 3.3 功能选项卡

#### 1. 🔍 查找参数
*   **功能**：在指定目录/文件中搜索特定参数名。
*   **输出**：列出包含该参数的所有文件路径及其当前值。

#### 2. 🗑️ 删除参数
*   **功能**：批量删除 XML 中的指定节点。
*   **智能处理**：支持连同 `<!--注释-->` 一起删除，保持代码整洁。

#### 3. 🔄 修改参数
*   **功能**：将指定参数的值更新为新值。
*   **格式**：`Param Name` ：`{value1,value2}`。
*   **安全提示**：操作前会弹窗二次确认，防止误操作。

#### 4. ➕ 添加参数
*   **功能**：向 XML 中注入新参数。
*   **格式**：`Param Name` ：`{value1,value2}`。
*   **高级选项**：支持添加“注释”。
*   **插入逻辑**：自动寻找 `</variable>` 或 `</Object>` 标签前插入。

#### 5. 📋 参数列表
*   **功能**：扫描目录下所有 XML，汇总所有出现过的参数名及其取值集合。

#### 6. ⚖️ 文件对比 (核心升级)
*   **功能**：对比 **本地电脑** 与 **远程服务器** 同名 XML 文件的差异。
*   **可视化布局**：
    *   **左侧 (Local)**：显示本地参数列表。
    *   **中间 (Arrows)**：提供 `→` (推送到远程) 和 `←` (拉取到本地) 按钮。
    *   **右侧 (Remote)**：显示远程服务器参数列表。
*   **状态标识**：
    *   **独有**：某一方有，另一方无。
    *   **不同**：双方都有，但值不一致。
*   **操作**：支持选中特定参数，点击箭头进行单向同步，或右键进行删除/覆盖操作。

## 4. 命令行 (CLI) 交互指南

若在无图形界面的 Linux 服务器上运行，将进入文本菜单模式。

### 4.1 主菜单流程
1.  **选择模式**：
    *   `1` - 本地模式
    *   `2` - 远程模式 (需输入 SSH 信息)
2.  **输入路径**：输入要处理的文件夹路径（本地模式）或远程绝对路径。
3.  **功能选择**：
    *   `1` 查找 / `2` 删除 / `3` 修改 / `4` 添加 / `5` 列出参数 / `0` 退出

### 4.2 远程模式交互
若选择远程模式，程序会先要求输入：
*   Host: `192.168.1.100`
*   Port: `22` (直接回车默认)
*   Username: `admin`
*   Password: `******`
连接成功后，所有操作指令将通过 SSH 发送到服务器执行。

## 5. 常见问题与解决方案

| 问题现象 | 可能原因 | 解决方案 |
| :--- | :--- | :--- |
| **SSH连接超时** | 网络不通或防火墙拦截 | 检查服务器 IP 是否可达，确认 22 端口是否开放。 |
| **读取文件失败** | 编码格式不支持 | 脚本已内置 `chardet` 自动检测，若仍报错，尝试将文件另存为 UTF-8 格式。 |
| **参数修改无效** | XML 格式嵌套复杂 | 本工具基于正则匹配 `<variable name="xxx">`。如果 XML 结构非标准（如属性换行），可能匹配失败。 |
| **GUI 启动报错** | 缺少 tkinter 库 | Linux 环境下可能需要安装 `python3-tk` 包，或直接使用 CLI 模式。 |

---

## 6. 安全与备份建议

由于该工具支持**批量删除**和**远程覆盖**，请务必遵守以下安全准则：
1.  **数据备份**：在执行“批量修改”或“对比同步”前，建议先备份原始 XML 文件夹。
2.  **权限控制**：远程 SSH 登录建议使用具有最小权限的专用账号，避免使用 `root` 账号直接操作。
3.  **网络稳定**：在进行远程文件写入时，请确保网络连接稳定，防止文件传输中断导致 XML 损坏。

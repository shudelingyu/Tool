### 📂 工具管理面板说明文档

#### 1. 概述
这是一个现代化的 GUI 应用程序启动器，用于统一管理和运行分布在不同目录下的独立工具。它不仅是一个简单的快捷方式集合，还具备日志记录、文件完整性检查和独立日志查看器等高级功能。

#### 2. 系统架构与依赖
- **核心语言**：Python 3.x
- **GUI 库**：`ttkbootstrap` (提供现代化 Flatly 主题) & `tkinter` (原生控件)
- **核心功能**：
  - **配置驱动**：通过 `programs.json` 动态加载工具列表。
  - **进程管理**：使用 `subprocess` 启动外部程序。
  - **日志系统**：实时记录操作日志到 `launcher.log`。

#### 3. 安装与配置
**3.1 运行环境**
- 确保已安装 Python 3.6+。
- 安装依赖库：
  ```bash
  pip install ttkbootstrap
  ```

**3.2 目录结构**
请在项目根目录下保持以下结构：
```text
Project_Folder/
├── launcher.py          # 主程序
├── programs.json        # 工具配置文件
├── launcher.log         # (自动生成) 运行日志
└── tool/                # (建议) 存放被管理工具的子目录
    └── XmlTool.exe
```

**3.3 配置文件 (`programs.json`)**
该文件定义了所有可管理的工具。请在程序运行前编辑此文件。

**配置示例：**
```json
[
  {
    "name": "Xml管理工具",
    "path": "tool/XmlTool.exe",
    "desc": "用于处理批量处理xml参数",
    "icon": "📄",
    "category": "开发工具"
  },
  {
    "name": "数据清洗器",
    "path": "data_cleaner.exe",
    "desc": "清理杂乱数据",
    "icon": "🧹"
  }
]
```
*注意：`icon` 字段支持 Emoji 表情符号。*

#### 4. 界面功能详解

**4.1 主界面布局**
- **左侧边栏 (Sidebar)**：
  - **Logo 与标题**：显示应用名称。
  - **导航菜单**：包含“全部工具”、“刷新列表”、“运行日志”三个功能按钮。
  - **统计信息**：显示当前加载的工具总数。
- **主工作区 (Main Area)**：
  - **标题栏**：显示当前视图名称。
  - **搜索框**：支持实时模糊搜索工具名称或描述。
  - **工具网格**：以卡片形式展示所有工具。

**4.2 工具卡片 (Tool Card)**
- **图标 (Icon)**：展示配置文件中定义的 Emoji。
- **名称与描述**：展示工具名称和简短描述。
- **状态反馈**：
  - **正常**：显示“🚀 启动”按钮，点击运行程序。
  - **缺失**：若程序路径不存在，显示“❌ 文件缺失”提示，启动按钮变灰。

**4.3 日志系统 (Log System)**
- **日志存储**：所有操作记录在根目录的 `launcher.log` 中。
- **独立日志窗口**：
  - **访问方式**：点击侧边栏“运行日志”或主界面右上角按钮。
  - **功能**：
    - **自动刷新**：每 3 秒自动拉取最新日志。
    - **颜色高亮**：INFO（绿色）、WARNING（黄色）、ERROR（红色）。
    - **操作按钮**：支持“刷新”、“清空日志”、“导出日志”。

#### 5. 操作指南

| 功能 | 操作步骤 | 说明 |
| :--- | :--- | :--- |
| **启动工具** | 点击工具卡片上的 **🚀 启动** 按钮 | 程序将在后台独立运行，互不干扰 |
| **搜索工具** | 在右上角搜索框输入关键词 | 支持模糊匹配名称和描述 |
| **刷新列表** | 点击侧边栏 **🔄 刷新列表** | 当 `programs.json` 被外部修改后，点击此按钮重新加载 |
| **查看日志** | 点击侧边栏 **📊 运行日志** | 查看详细的启动记录和错误信息 |

#### 6. 故障排查

- **Q: 点击启动无反应？**
  - A: 检查 `programs.json` 中的 `path` 路径是否正确（区分大小写）。如果路径错误，卡片会显示“文件缺失”。
- **Q: 界面出现报错弹窗？**
  - A: 请检查 `launcher.log` 文件，通常是因为 JSON 格式错误（如缺少逗号或括号）导致配置加载失败。
- **Q: 搜索功能无效？**
  - A: 请确保搜索关键词与配置文件中的 `name` 或 `desc` 字段匹配。

*注意：`programs.json` 需要与生成的 `.exe` 文件放在同一目录下。*

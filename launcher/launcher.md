# 📂 工具管理面板 使用说明

**适用程序：** `launcher/launcher.py`
**界面框架：** customtkinter（浅色主题）
**配置文件：** `programs.json`（与程序同目录）

---

## 1. 工具概览

这是一个独立的**工具启动器**：把散落在不同目录的 exe/脚本集中展示成卡片，点一下即可启动，并提供搜索、缺失检测、运行日志与**可视化添加工具**功能。

核心能力：

* **配置驱动**：所有工具来自 `programs.json`，增删改都只动这一个文件。
* **启动隔离**：用 `subprocess.Popen` 拉起目标程序，各工具互不影响，也不阻塞面板。
* **缺失检测**：启动时后台检查各工具路径，缺失会弹出提示并写入日志。
* **运行日志**：操作记录写入 `launcher.log`，内置独立日志窗口，支持刷新/清空/导出。
* **图形化添加**：点“➕ 添加工具”，选择路径、填写名称描述后**自动写回** `programs.json`。

---

## 2. 运行方式

### 2.1 源码运行

```bash
pip install customtkinter
python launcher/launcher.py
```

### 2.2 运行打包后的 exe

直接双击 `launcher.exe` 即可。

> `programs.json` **没有**被打进 exe（`launcher.spec` 中 `datas=[]`）。
> 首次运行且没有该文件时，面板从**空列表**开始，点“➕ 添加工具”后会自动在 exe 同级创建它。
> 想保留原有工具列表，把 `programs.json` 一起拷到 exe 同级即可。

## 3. 目录结构

```text
launcher/                  # 或打包后的 launcher/ 文件夹
├── launcher.py            # 主程序
├── programs.json          # 工具列表（首次添加工具时自动创建）
├── launcher.ico           # 程序图标
├── launcher.log           # (自动生成) 运行日志
└── launcher.spec          # PyInstaller 打包配置
```

## 4. 配置文件 programs.json

根节点是一个数组，每个元素代表一个工具：

| 字段 | 必填 | 说明 |
| :--- | :---: | :--- |
| `name` | ✅ | 卡片标题，也是搜索匹配字段之一 |
| `path` | ✅ | 程序路径。**相对路径**相对程序所在目录，**绝对路径**直接使用（推荐，便于跨目录引用） |
| `desc` | ❌ | 卡片描述；超过 50 字会被截断并加 `...` |
| `icon` | ❌ | 卡片图标，填 Emoji；缺省为 `🔧` |

示例：

```json
[
  {
    "name": "Xml参数管理工具",
    "path": "D:/YC_Tool/xmlTool/dist/XmlTool.exe",
    "desc": "用于批量处理 xml 参数",
    "icon": "📄"
  },
  {
    "name": "测试工具",
    "path": "tool/TestTool.exe",
    "desc": "放在面板目录 tool 子目录下的相对路径写法",
    "icon": "🧪"
  }
]
```

要点：

* 路径写法遵循系统规则（Windows 下 `/` 与 `\` 均可）。
* 手改这个文件后，点侧边栏 **🔄 刷新列表** 即可生效，无需重启。
* 面板**只会读取**上述四个字段，其他自定义字段会被保留但不会显示。

## 5. 界面说明

```text
┌──────────────┬──────────────────────────────────────────────┐
│ 🛠️ 工具箱     │  工具管理中心                 [🔍 搜索工具...] │
│              │                                              │
│ 📦 N 个工具   │  ┌────────┐ ┌────────┐ ┌────────┐            │
│              │  │  📄    │ │  📊    │ │  🧪    │            │
│ 📋 全部工具   │  │ 名称   │ │ 名称   │ │ 名称   │            │
│ 🔄 刷新列表   │  │ 描述   │ │ 描述   │ │ 描述   │            │
│ 📊 运行日志   │  │ 🚀启动 │ │ 🚀启动 │ │ 文件缺失│            │
│              │  └────────┘ └────────┘ └────────┘            │
│ ➕ 添加工具   │                                              │
│              │                                              │
│ Made with TC │                                              │
└──────────────┴──────────────────────────────────────────────┘
```

### 5.1 左侧边栏

| 元素 | 作用 |
| :--- | :--- |
| 📦 N 个工具 | 当前配置中的工具总数，增删后即时更新 |
| 📋 全部工具 | 清空搜索条件并重新加载全部卡片 |
| 🔄 刷新列表 | 重新读取 `programs.json`（外部修改后点它），并检查缺失文件 |
| 📊 运行日志 | 打开独立日志窗口（已打开则前置显示） |
| ➕ 添加工具 | 打开“添加工具”对话框，见 6.5 |

### 5.2 主区域

* **搜索框**：输入即实时过滤，匹配 `name` 与 `desc`（不区分大小写）；无结果时显示“😔 没有找到相关工具”。
* **工具卡片**：三列网格，每张卡片含图标、名称、描述与操作区。
* **操作区状态**：
  * 路径存在 → 显示 **🚀 启动** 按钮；
  * 路径不存在 → 显示 **❌ 文件缺失**，不可点击。

### 5.3 日志窗口

* 打开后**每 3 秒自动刷新**一次，也可手动点“🔄 刷新”。
* 顶部显示日志文件完整路径。
* 三个按钮：
  * **🔄 刷新**：立即重新读取日志；
  * **🗑️ 清空**：清空 `launcher.log`，完成后弹出成功提示；
  * **💾 导出**：另存为 `.log` / `.txt`。
* 日志格式：`[时间] [级别] 内容`，级别包括 `INFO` / `WARNING` / `ERROR`。

## 6. 常用操作

### 6.1 启动工具

点击卡片上的 **🚀 启动**。面板会：

1. 在右下角弹出“启动 xxx...”提示；
2. 以无控制台窗口方式拉起程序（`CREATE_NO_WINDOW`）；
3. 写入一条 `INFO` 日志。

> 启动时未指定 `cwd`，目标程序的工作目录继承面板进程的当前目录（通常是面板所在目录）。
> 若目标程序依赖相对路径读取同目录文件，请先手动在其目录下试运行确认。
> 面板与目标程序互相独立，关闭面板不会关掉已启动的工具。

### 6.2 搜索工具

在右上角搜索框输入关键词，卡片实时过滤。清空输入即恢复全部。

### 6.3 刷新列表

手动改过 `programs.json` 或增删了工具文件后，点 **🔄 刷新列表**：
重新读取配置 → 更新总数 → 重绘卡片 → 检查缺失文件 → 提示“刷新完成”。

### 6.4 查看 / 导出运行日志

点 **📊 运行日志**。窗口内可刷新、清空、导出；关闭窗口后如需再看，再次点击即可重新打开。

### 6.5 添加工具（图形化）

1. 点侧边栏 **➕ 添加工具**；
2. 点 **浏览...** 选择目标程序（`.exe` / `.py` / 任意文件均可）；选中后**名称会自动取文件名**，可再修改；
3. 填写**描述**（可选）与**图标**（Emoji，可留空，默认 `🔧`）；
4. 点 **保存**。

保存时程序会：

* 校验路径是否存在；
* 检查该路径是否**已经添加过**（重复会提示并中止）；
* 把新条目追加到 `programs.json` 并整体重写（文件不存在则自动创建；保持中文不转义、两空格缩进）；
* 刷新卡片列表与“N 个工具”统计，弹出“已添加 xxx”提示，并记一条日志。

路径存储规则：

| 目标位置 | 保存形式 | 示例 |
| :--- | :--- | :--- |
| 在面板目录内 | 相对路径 | `tool/TestTool.exe` |
| 在面板目录外 / 其他盘符 | 绝对路径 | `D:/Apps/TestTool.exe` |

> 相对路径便于把整个工具箱目录拷到别的电脑后仍可使用。

---

## 7. 打包为 exe

```bash
cd launcher
pyinstaller launcher.spec
```

产物在 `dist/launcher/`。`programs.json` 不是必须预置的：没有时面板为空列表，添加第一个工具会自动创建；需要沿用旧列表时再把它拷到 `launcher.exe` 同级。

## 8. 常见问题

| 问题 | 原因 | 处理 |
| :--- | :--- | :--- |
| 卡片显示“❌ 文件缺失” | `path` 指向的文件不存在 | 用绝对路径，或把工具放到面板目录下用相对路径 |
| 启动无反应或闪退 | 目标 exe 依赖缺失 / 路径填错 | 先手动双击该 exe 验证；再看日志中的启动路径 |
| 启动应用后弹“配置错误” | `programs.json` JSON 语法错误（缺逗号/括号） | 用编辑器或 JSON 校验工具修正；错误详情见 `launcher.log` |
| 添加后卡片没出现 | 搜索框里还有过滤关键词 | 清空搜索或点“📋 全部工具” |
| 拷到别的电脑后工具列表为空 | 只拷了 exe，没拷 `programs.json` | 把原 `programs.json` 放到 exe 同级，或在新机器上重新添加 |
| 日志窗口内容不更新 | 日志窗口已关闭 | 重新点侧边栏“📊 运行日志” |
